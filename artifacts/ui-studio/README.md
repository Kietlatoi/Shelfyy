# UI previews — 2026-11-01

These are browser captures of the actual React Native screen components rendered
through React Native Web, with local API/auth/image-picker fixtures and bundled
brand/icon fonts. They use demonstration data, not production account data.

- `overview.jpg` / `index.html`: home, wardrobe, and AI try-on comparison.
- `*-390.jpg`: individual 390×844 captures.
- `trial-360.jpg`: 360×640 capture.

These images do not verify Android rendering, keyboard behavior, native
permissions, Firebase authentication, or real purchases. See
`docs/mobile-studio-ui.md` for validation scope.
